# Design A Level

Read the project profile and upstream requirements. Define a stable level ID, player route, entry/exit state, interaction map, camera and representation rules, navigation/collision, lighting/readability, asset dependencies, streaming boundaries, and performance budget.

For investigation content, map each clue to a visible placement, observation condition, and failure-safe route. For 2.5D, state the concrete form, axes, collision, occlusion, parallax, and pick behavior. Write the level specification only after review against the baseline and its dependent systems.
