# Design UX

Specify user journeys, screen states, input paths, information hierarchy, error and empty states, localization expansion, controller and keyboard support, and accessibility alternatives. UI owns presentation and input feedback, not game-state truth. Link each screen and interaction to the owning system requirement and acceptance evidence.

For audio-dependent mechanics, ensure an equivalent visual path. For narrative or investigation interfaces, do not expose spoiler-only truth data. Treat implementation as planned until the baseline and architecture identify the Godot UI approach.
