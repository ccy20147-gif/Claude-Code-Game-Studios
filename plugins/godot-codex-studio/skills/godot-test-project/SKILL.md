# Test A Godot 4 Project

Map tests to requirement IDs and work-item acceptance conditions. Separate deterministic unit/config checks, engine integration, visual/UI checks, runtime journeys, fresh-tester checks, soak, and package validation. Record build identity, platform, execution method, raw logs or artifact hash, result, and signer.

Local editor-dependent tests may close a work item only after their required evidence level. Cloud-generated code or reports remain `PENDING_LOCAL_VALIDATION`. A `solo` review does not waive smoke, regression, save compatibility, security, or release checks.
