# Run A Prototype

State one falsifiable hypothesis, success metric, timebox, input fixture, and decision rule. Keep prototype code, GDScript/C#s, and `.tres/.res` files isolated from production. Capture evidence at the appropriate level and report `PROCEED`, `PIVOT`, or `STOP` with assumptions that remain untested.

Do not promote prototype implementation automatically. Only an approved spec, report, and legally cleared source asset may seed a new production work item after review.
